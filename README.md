# Poker Lab

Офлайн-прототип для учебного разбора раздач Texas Hold’em.

## Файлы
- `index.html` — более поздняя версия раннего прототипа: ручной ввод карт, Monte Carlo equity, pot odds и упрощённый EV колла.
- `archive/poker_lab_early.html` — предыдущая версия прототипа.

## Запуск
Откройте `index.html` в современном браузере. Внешние библиотеки и сервер для базового запуска не требуются.

## Ограничения
Это ранний прототип, не солвер и не полноценный парсер hand history. Результаты Monte Carlo приближённые и зависят от предположения о случайных руках соперников. Используйте для обучения и анализа после раздачи либо в средах, где помощники разрешены. Не подключайте к запрещённым live-столам.

Более богатая версия Poker Lab preview и полноценная интеграция с Telegram в этих двух HTML-файлах не содержатся.
