# RiverLab Poker

Одностраничное интерактивное приложение для ручного ведения покерной раздачи и просмотра матрицы стартовых рук.

## Возможности

- Стол на 10 мест с именами игроков и стеками.
- Ручная запись действий: фолд, чек, колл, бет, рейз и олл-ин.
- Ручное ведение банка, борда и улицы.
- Базовые показатели профиля игрока на основе введённых действий.
- Матрица 169 стартовых рук с ориентировочной категорией силы.
- Экспорт сессии в JSON и импорт ранее экспортированной сессии.

## Запуск

Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages. Сборка и сервер не требуются.

## Ограничения

Это локальный прототип: данные не сохраняются на сервере автоматически. Матрица показывает ориентировочную силу стартовой руки, а не точное эквити. Нет подключения к покерным клиентам, автоматического захвата экрана или полноценного парсера hand history.
